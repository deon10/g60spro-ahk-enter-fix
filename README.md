The AutoHotKey script will send an enter key press whenever the Menu Pick USB code is sent via the G60S Pro remote, using the USB dongle.

# How to use

Open `G60s Pro OK Remap - AHK Script.ahk` and set the line `#Include C:\Users\test\Documents\AutoHotkey\Lib` to point to your AHK lib directory containing `AHKHID.ahk`

Open run `G60s Pro OK Remap - AHK Script.ahk` in AHK
